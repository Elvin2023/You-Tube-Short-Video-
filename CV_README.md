# Senior Web and Digital Marketing Specialist CV

## Overview
This repository now includes a professional CV template for a Senior Web and Digital Marketing Specialist role.

## Files
- **cv.html** - The main CV webpage
- **cv-style.css** - Stylesheet for the CV with responsive design

## How to Use

### View in Browser
1. Simply open `cv.html` in any modern web browser
2. The CV will display with full styling and responsiveness

### Customize the CV
1. Open `cv.html` in a text editor
2. Replace the placeholder information with your own:
   - Name and contact details in the header
   - Professional summary
   - Work experience details
   - Education information
   - Skills and certifications
   - Achievements

### Print or Export to PDF
1. Open `cv.html` in your browser
2. Use the browser's Print function (Ctrl+P or Cmd+P)
3. Select "Save as PDF" as the destination
4. The CV includes print-optimized styles for professional output

## Features
- ✅ Clean, modern design with professional gradient header

5. Education

7. Notable Achievements

## Customization Tips
- Colors can be changed in `cv-style.css` (look for gradient: #667eea and #764ba2)
- Add or remove sections as needed
- Adjust font sizes in the CSS for personal preference
- The CV is structured with semantic HTML5 for easy modification
